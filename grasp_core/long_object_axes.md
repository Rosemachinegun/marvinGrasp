# 长条物体轴约定

适用于 `pen` 和 `*_screwdriver_handle`。

| 使用位置 | X | Y | Z |
| --- | --- | --- | --- |
| 感知输出、JSON、显示、目标 TF | 水平长轴 | 水平短轴 | 基座 +Z |
| 抓取策略、`pose_relative` | 水平长轴 | 水平短轴 | 基座 +Z |
| 夹爪 TCP | — | 闭合轴 | 接近轴 |

感知、抓取和 YAML 不再交换 X/Y。两类物体均以夹爪局部 Y 对齐物体
局部 Y，即沿短轴闭合。统一坐标系中 `Y = Z × X`，且 `X × Y = Z`。
左右手只影响等价腕姿选择，不改变物体轴符号。

感知归一化在 `run_flowpose_job` 中、可视化和保存之前执行，独立于
`use_cube_z_symmetry_grasp_policy`。使用实际 `base_to_camera` 外参定义
Z-up；JSON 中的 pose 仍表达在相机坐标系中，不能直接要求其第三列为
`[0, 0, 1]`，应先转换至基座坐标系。

FlowPose 的通用校正包含轴置换，但旧实现的尺寸没有随之置换。
长条物体因此使用校正前 `last_raw_pose` 与原始 `length_all` 配对，取最大
尺寸对应的轴作为长轴，再投影到基座 XY 平面。无有效水平分量、非有限值、
非法旋转或非法尺寸会报错。原始长轴符号保留，不额外猜测笔尖或手柄端点。

尺寸按照 `abs(R_new.T @ R_raw) @ size_raw` 重算，以包围原始倾斜包围盒。
`objects.pose/size` 与 `pose_all/length_all` 同步更新；归一化物体的显示
包围盒也使用相同的姿态、尺寸。新 JSON 保存 `raw_pose_all`、
`raw_length_all` 以及轴约定版本，便于回溯。

历史 JSON 的原文件不会被改写。读取目标时沿用旧系统的局部 X 长轴约定
并重建 Z-up，以兼容原有模板。没有校正前姿态的旧文件，其尺寸与原始轴
对应关系无法可靠恢复，因此历史尺寸不作自动猜测；需要重新推理才能保证
与新输出一样的完整尺寸对应关系。
